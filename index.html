Quick link inspection

MEGA Folder Viewer

Paste a public MEGA folder link to see its files, folders, sizes, and paths. It reads the listing only; it does not download file contents.

Your link is processed in this browser using the MEGAJS library. Don't paste private links you don't want to use here.

This page uses the public share link to request the folder listing from MEGA. A slow connection may affect how quickly MEGA responds. No file data is downloaded.
